Overview

This is part of a larger DD-WRT project. This page describes the process I used to install DD-WRT on my NETGEAR R7000 router.

Technical Details

Host Computer:
The host computer I used is an HP ZBook G14 running Debian 12 (bookworm).

Router:
The router used is a NETGEAR R7000 Nighthawk router.

Steps

  1. TURN OFF ALL INTERFACES EXCEPT FOR THE ETHERNET INTERFACE YOU WILL USE TO CONNECT TO THE ROUTER.
  2. Download the DD-WRT firmware image from the link above.
  3. Turn off the router.
  4. Connect your computer to the router via Ethernet.
  5. Find the name of the Ethernet interface that is connected to the router (in my case eno1).
  6. Execute the following command: 
    sudo nmrpflash -i {interface name} -f {path to firmware image}
  7. You should see the following: 
    Waiting for Ethernet Connection (Ctr-C to skip)
  8. Once you see this, turn the router back on and wait. The flashing process will automatically start.
    9. DO NOT TURN OFF COMPUTER, ROUTER, OR ETHERNET CABLE DURING THIS PROCESS
  9. Upon completion, you will see the following:
    10. Advertising NMRP server on eth2 ... /
    Received configuration request from {router MAC}
    Sending configuration: {IP}
    Received upload request: filename 'firmware'.
    Uploading{firmware image filename} ... OK (3539077 b)
    Waiting for remote to respond.
    Received keep-alive request (11).
    Remote finished. Closing connection.
    Reboot your device now.
  10. Now you're done! Reboot the device and connect to the router portal. You should see the following:
